# ISA LeadFlow — Sales Lead Management Portal

A high-performance SaaS analytics dashboard built to monitor and manage real estate sales leads generated by Inside Sales Agents (ISAs). Connects directly to Discord lead feeds, Google Sheets, and cloud PostgreSQL (Neon).

---

## Key Features

1. **Executive Dashboard Analytics**: Real-time KPIs (Total Leads, Sellers, Buyers, Today's Leads, Contact Rate), Daily Lead Generation Trend Area Chart, Donut Breakdown by Lead Type & Property Type, Geographic State Distribution, and Top ISA Leaderboard.
2. **All Leads Explorer**: Search, multi-field filters (date, type, property, state, contact status), column sorting, lead details modal, and Admin-only CSV export.
3. **Data Sync History (Admin Only)**: Audit trail of all synchronization runs, new leads added, error logs, and instantaneous Google Sheet sync triggers.
4. **User & Session Management**:
   - Role-Based Access Control (Admin vs. Agent).
   - Strict session termination on tab/window close.
   - Interactive logout modal with confirmation and animated progress bar.
   - Self-service password reset workflow notifying administrator.
5. **Modern Light/Royal Theme**: Clean light login portal with custom alerts paired with a vibrant royal cobalt blue sidebar.

---

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Recharts, Lucide Icons, Axios.
- **Backend**: Python FastAPI, SQLAlchemy 2.0, Uvicorn, Pydantic 2.
- **Database**: Neon Serverless PostgreSQL (with automatic local SQLite fallback).
- **External Ingestion**: Google Sheets CSV sync service.

## Deployment Options

### Option A: 1-Click Deploy on Render (Recommended)

1. Push your repository to GitHub.
2. In [Render Dashboard](https://dashboard.render.com), click **New +** -> **Blueprint**.
3. Select your GitHub repository. Render automatically reads `render.yaml`.
4. Fill in environment variables:
   - `DATABASE_URL`: Your Neon PostgreSQL connection string.
   - `GOOGLE_SHEETS_ID`: Your Google Sheet ID.
5. Click **Apply**. Render will install dependencies, build the React frontend, and boot FastAPI with Uvicorn.

### Option B: Deploy with Docker (Railway / Fly.io / VPS / DigitalOcean)

The repository includes a production-ready multi-stage `Dockerfile`:

```bash
# 1. Build Docker image
docker build -t isa-leadflow .

# 2. Run container
docker run -d -p 8000:8000 \
  -e DATABASE_URL="postgresql+psycopg2://user:pass@host/db?sslmode=require" \
  -e GOOGLE_SHEETS_ID="your_sheet_id" \
  -e SECRET_KEY="your_secure_secret_key" \
  --name isa-leadflow-app isa-leadflow
```

Or using `docker compose`:
```bash
docker compose up -d
```

### Option C: Split Deploy (Frontend on Vercel + Backend on Render/Railway)

1. **Backend (Render / Railway / Fly.io)**:
   - Deploy `backend/` folder.
   - Build Command: `pip install -r backend/requirements.txt`
   - Start Command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
   - Set `DATABASE_URL`, `GOOGLE_SHEETS_ID`, `SECRET_KEY`, and `CORS_ORIGINS=https://your-frontend.vercel.app`.

2. **Frontend (Vercel / Netlify)**:
   - Root Directory: `frontend`
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Environment Variable: `VITE_API_URL=https://your-backend-service.onrender.com`

## Environment Variables Reference

| Variable | Required | Description | Example |
|---|---|---|---|
| `DATABASE_URL` | Yes (in prod) | Neon / PostgreSQL connection string | `postgresql+psycopg2://neondb_owner:...@ep-xyz.aws.neon.tech/neondb?sslmode=require` |
| `GOOGLE_SHEETS_ID` | Yes | Google Sheet ID containing Discord leads | `1Icznd3xhx8hEdJFH-VsdqFPsYqeoixGQlv9L6TaH5so` |
| `SECRET_KEY` | Recommended | Secret key for secure session generation | Random 32+ character string |
| `CORS_ORIGINS` | Optional | Comma-separated allowed frontend origins | `https://my-app.vercel.app,https://leadflow.mycompany.com` |
| `PORT` | Optional | Port for the Uvicorn web server (defaults to 8000) | `8000` |
| `VITE_API_URL` | Optional (split deploy) | Backend API URL for frontend production bundle | `https://api.isaleadflow.com` |
